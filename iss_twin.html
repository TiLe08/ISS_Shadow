Quick guide

The console mirrors the real ISS from NASA's public telemetry. The 3D station, the ground track and the side panels update live.

  • Channels Click any widget, value or chip in the side panels to graph it, add it to the dashboard or open it in the channel browser.
  • Channel browser Searches all 337 public channels and shows a description and a 3 h trend for each.
  • Dashboard Your own layout: groups of widgets (value, graph, bar, gauge, dial, state), the 3D view, the ground track and any panel. Use Edit layout to drag, resize and rename.
  • Command Forks a virtual ISS you can steer. The real station is never commanded.
  • Layout Panel headers collapse and expand. Drag the thin lines between areas to resize them.

Setup

Drag the thin lines between panels, the map's top edge and the command window's left edge to resize.

MQTT is the normal mode: the start file runs the broker and the telemetry bridge in the background. LIVE connects the browser straight to NASA's feed (no logging, no command acknowledgement). NASA orbit predictions are fetched independently by the launcher in both MQTT and Live modes. Orbit labels distinguish predictions from measurements. Hover the orbit badge for the NASA product date and validity. Commands are only sent in MQTT mode.
